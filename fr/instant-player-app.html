instant PLAYER

Soundboard de 64 pads pour le direct, le théâtre, le podcast et le studio. Un toucher lance la lecture, un second l’arrête. Superposez les sons en mode MULTI, passez de l’un à l’autre en fondu enchaîné en mode SINGLE. Points forts

64 pads. Un toucher. Le cue part.

instant PLAYER est un soundboard de 64 pads dans le style des cart machines de studio. 16 pads par banque, 4 banques, modes MULTI et SINGLE, AUTO-CUE, LOOP, fondu enchaîné en option. Tout le spectacle tient dans un seul bundle .satkip, transférable par AirDrop vers l’iPad suivant et immédiatement opérationnel.

64 Pads

16 pads x 4 banques

64 emplacements de cues, répartis en quatre banques (A / B / C / D) de 16 pads chacune. Pour chaque pad : nom, couleur (palette de 7 couleurs), curseur de volume, commutateur LOOP, commutateur AUTO-CUE. Mini-forme d’onde avec marqueur de cue directement sur chaque pad.

Multi · Single

Mode MULTI ou SINGLE

MULTI : les pads se superposent, chaque toucher ajoute une voix. SINGLE : chaque toucher arrête d’abord tout le reste, comme une cart machine de studio classique. SINGLE avec FADE > 0 donne un fondu enchaîné propre entre les cues.

Fade

Quatre niveaux de FADE

Le bouton FADE fait défiler OFF / SHORT / MEDIUM / LONG (0,5 / 1,5 / 4 s), global pour tous les pads. En mode SINGLE, il devient automatiquement un fondu enchaîné. Pas de clic à l’arrêt, pas de coupure sèche sur les stings.

Auto-Cue

AUTO-CUE + LOOP

AUTO-CUE saute le silence initial : les cues partent au premier échantillon audible, pas au début du fichier. Commutateur LOOP pour les tapis et les ambiances, avec retour au point de cue. Les deux s’activent pad par pad.

Show-Bundle

Bundle .satkip

Tout le spectacle, le manifeste et tous les WAV 24 bits dans un seul fichier ZIP .satkip. Transférez-le par AirDrop vers l’iPad suivant, ouvrez-le, et le spectacle est immédiatement prêt. Pas de nouveau chargement, pas de cloud, pas de compte.

Round-Trip

Aller-retour avec easy EDITOR

Le bouton CHOOSE envoie le pad actif vers pegelWERK easy EDITOR. Coupez-le ou normalisez-le selon R128, puis SEND BACK le renvoie automatiquement dans le même pad. Sans easy EDITOR, un message renvoyant vers l’App Store s’affiche à la place.

Fonctionnement

Le spectacle prêt en 4 étapes

Touchez un pad, choisissez l’audio, réglez le mode, enregistrez le spectacle. Même utilisation sur iPhone (portrait et paysage) et sur iPad (les quatre orientations).

01

Affecter un pad

Touchez un pad vide, le sélecteur de fichiers s’ouvre. Choisissez l’audio dans l’app Fichiers, sur iCloud Drive ou par AirDrop. Le pad affiche aussitôt un aperçu de la forme d’onde avec marqueur de cue.

02

Régler le pad

Volume par curseur, une des 7 couleurs pour la tuile du pad, LOOP pour les tapis, AUTO-CUE pour des départs de cue propres. En option, envoi vers easy EDITOR pour couper.

03

Choisir le mode

Mode MULTI pour superposer, mode SINGLE pour la logique de cart machine. FADE sur SHORT / MEDIUM / LONG pour des fondus enchaînés entre les cues. ESC arrête tout, Fade-All arrête proprement en fondu tous les pads en cours de lecture.

04

Enregistrer le spectacle

SAVE écrit un fichier .satkip avec le manifeste et tous les sons en WAV 24 bits. Par AirDrop ou via Fichiers vers l’iPad suivant, un double toucher, et le spectacle est prêt.

Détails techniques

Conçu pour le direct

App iOS native sur moteur audio JUCE. Audio en arrière-plan activé, pour que les cues continuent de jouer écran verrouillé.

Moteur de pads

  • Slots 64 (4 Banks x 16)
  • Voices 64 (1 pro Slot)
  • Per-Pad Name · Farbe · Vol
  • LOOP Retour au point de cue
  • AUTO-CUE Stille-Skip am Anfang
  • Forme d’onde Mini-aperçu avec marqueur de cue

Modes & commandes

  • Mode MULTI · SINGLE
  • FADE OFF · 0,5 · 1,5 · 4 s
  • Tastatur 1234 · QWER · ASDF · ZXCV
  • Banks F5 · F6 · F7 · F8
  • Stop All ESC
  • Master-Vol iPad (iPhone via HW-Tasten)

Plateforme & E/S

  • iPhone Hoch + Quer
  • iPad alle 4 Orientierungen
  • Input WAV · AIFF · MP3 · M4A · FLAC · OGG
  • Show .satkip (ZIP avec WAV 24 bits)
  • Background Audio-Mode aktiv
  • URL-Scheme instantplayer://
Ce qui le distingue

Un spectacle.
Un fichier.

Ce qui le distingue des soundboards génériques, c’est le bundle .satkip : le manifeste et tous les WAV 24 bits dans un seul ZIP. Une soirée de théâtre, un épisode de podcast, un set live, chacun entièrement transportable. Oubliez la clé USB, oubliez « quels sons vont avec quel spectacle » : envoyez simplement le bundle par AirDrop, et la configuration est là où elle doit être.
