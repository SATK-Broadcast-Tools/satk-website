Points forts

Un fichier entre, un fichier sort.

loudness CORRECT sur iPad est la version mobile de l’outil de bureau : même moteur, mêmes presets, mêmes configurations surround. En mise en page paysage pour un contrôle à l’échantillon près.

16 Presets

De R128 à YouTube

EBU R128, R128 S1, ATSC A/85, ARIB TR-B32, AGCOM, FreeTV OP-59, DPP, Portaria 354, Netflix, Apple Podcasts, Spotify, Amazon Music, YouTube, Leq(m)-85, Leq(a)-85 et Custom : toutes les cibles dans une seule liste.

Two-Pass

Verify-and-Refine

La passe 1 mesure, la passe 2 écrit avec le gain de correction. Si le résultat s’écarte de plus de 0,1 LU de la cible, une passe d’affinage supplémentaire est lancée automatiquement. Pas d’« à peu près ».

True Peak

Limiteur polyphase 4x

Protection contre les crêtes inter-échantillons avec 5 ms d’anticipation et un relâchement exponentiel de 50 ms. Enveloppe à double constante de temps : pas d’effet de pompage, pas de distorsion sur les transitoires.

Surround

Du mono au 9.1.6

Jusqu’à 16 canaux : mono, stéréo, 5.1, 6.1, 7.1, 7.1.2, 7.1.4, 9.1.4, 9.1.6. Quatre configurations de routage (Auto/ITU, Film L-C-R, DTS, Raw/Stems). LFE conforme BS.1770 avec un poids de 0, canaux surround à 1,41, exactement selon la norme.

LRA

Remodelage 3 bandes

Activable en option si le LRA est trop élevé. Filtre Linkwitz-Riley du 4e ordre avec séparation à <= 150 Hz et >= 3 kHz. Compression à genou doux par bande avec constantes de temps propres à chaque bande, reconstruction parfaite.

Fonctionnement

4 étapes jusqu’au fichier prêt pour la validation

Choisissez le fichier, réglez la configuration et le preset, ANALYZE CORRECT, terminé. Verify-and-Refine s’exécute en arrière-plan.

01

Choisir le fichier

WAV, AIFF, FLAC, MP3 depuis l’app Fichiers, iCloud Drive ou par AirDrop. Jusqu’au 9.1.6 (16 canaux).

02

Configuration & preset

Auto/ITU pour le multicanal standard, Film/DTS/Raw pour les cas particuliers. Preset parmi 16 cibles ou Custom.

03

ANALYZE CORRECT

La passe 1 mesure l’Integrated LUFS et le TP max. La passe 2 écrit avec le gain de correction et le limiteur TP. Passe d’affinage si l’écart dépasse 0,1 LU.

04

Sortie dans Fichiers

Le fichier corrigé est enregistré dans les documents de l’app. Partageable aussitôt via l’app Fichiers, AirDrop, Mail ou clé USB-C.

Détails techniques

Conçu pour le broadcast

Moteur DSP identique à celui de la version de bureau. Reproductible à l’échantillon près, toutes les valeurs sont à nouveau vérifiées par rapport à la norme à la fin de la passe 2.

Normes & DSP

  • Loudness ITU-R BS.1770-4
  • K-Weight Pre + RLB
  • Gating 400 ms · 75 % Overlap
  • LRA EBU Tech 3342
  • TP-Limiter 4x polyphase FIR
  • Lookahead 5 ms · Release 50 ms

Canaux & routage

  • Channels Mono bis 9.1.6 (16)
  • Layouts Auto · Film · DTS · Raw
  • LFE-Gewicht 0 (BS.1770-konform)
  • Surround 1,41 (Power-Domain)
  • LRA-Bands <= 150 / 150-3000 / > 3000 Hz
  • Filter Linkwitz-Riley 4. Ordnung

Plateforme & E/S

  • OS iPadOS 16+ (iPad-only)
  • Bundle com.satk.loudnesscorrect
  • Orient. Landscape (Left + Right)
  • Input WAV · AIFF · FLAC · MP3
  • Output WAV · AIFF · 16/24/32-Bit
  • UI Dark, Full-Screen, English
Ce qu’il n’est pas

Pas un loudness-mètre temps réel.

loudness CORRECT est un outil de correction hors ligne, pas un loudness-mètre en direct. Il mesure tout le fichier, planifie la correction, réécrit le fichier et vérifie le résultat. Pour la loudness en temps réel, prenez pegelWERK loudness METER PRO. Pour amener un mixage terminé dans le bon couloir de loudness, c’est l’outil qu’il vous faut.
