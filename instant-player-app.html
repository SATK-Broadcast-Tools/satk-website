Highlights

64 Pads. Tippen. Cue läuft.

instant PLAYER ist ein 64-Pad-Soundboard im Studio-Cart-Stil. 16 Pads pro Bank, 4 Bänke, MULTI- und SINGLE-Mode, AUTO-CUE, LOOP, optionaler Cross-Fade. Komplette Show als ein .satkip-Bundle portabel, per AirDrop aufs nächste iPad und sofort einsatzbereit.

64 Pads

16 Pads x 4 Banks

64 Cue-Slots, organisiert in vier Banks (A / B / C / D) mit je 16 Pads. Pro Pad: Name, Farbe (7-Farben-Palette), Lautstärke-Slider, LOOP-Toggle, AUTO-CUE-Toggle. Mini-Wellenform mit Cue-Marker direkt auf jedem Pad.

Multi · Single

MULTI- oder SINGLE-Mode

MULTI: Pads stapeln Stimmen, jeder Tipp legt eine weitere drauf. SINGLE: jeder Tipp stoppt zuerst alles andere, wie eine klassische Studio-Cart-Maschine. SINGLE plus FADE > 0 ergibt einen sauberen Cross-Fade zwischen Cues.

Fade

Vier FADE-Stufen

FADE-Knopf zyklt OFF / SHORT / MEDIUM / LONG (0,5 / 1,5 / 4 s), global für alle Pads. Im SINGLE-Mode wird das automatisch zum Cross-Fade. Kein Klick beim Stoppen, kein hartes Cut bei Stings.

Auto-Cue

AUTO-CUE + LOOP

AUTO-CUE überspringt Anfangsstille, Cues feuern beim ersten hörbaren Sample, nicht beim Datei-Anfang. LOOP-Toggle für Beds und Ambient-Material, Wraparound zum Cue-Punkt. Beides pro Pad zuschaltbar.

Show-Bundle

.satkip-Bundle

Komplette Show, Manifest und alle 24-Bit-WAVs, in einer einzigen .satkip-ZIP-Datei. Per AirDrop aufs nächste iPad, dort öffnen, Show ist sofort einsatzbereit. Kein Re-Upload, keine Cloud, kein Account.

Round-Trip

Roundtrip mit easy EDITOR

CHOOSE-Button schickt das aktive Pad an pegelWERK easy EDITOR. Dort trimmen oder R128-normalisieren, mit SEND BACK kommt das Ergebnis automatisch ins selbe Pad zurück. Ohne easy EDITOR erscheint stattdessen ein App-Store-Hinweis.

Funktionsweise

In 4 Schritten zur Show

Pad antippen, Audio wählen, Mode setzen, Show speichern. Auf iPhone (Hoch- und Querformat) und iPad (alle vier Orientierungen) gleich bedienbar.

01

Pad belegen

Leeres Pad antippen, der Files-Picker öffnet sich. Audio aus Dateien-App, iCloud Drive oder per AirDrop wählen. Pad zeigt sofort eine Wellenform-Vorschau mit Cue-Marker.

02

Pad einstellen

Lautstärke per Slider, eine der 7 Farben für die Pad-Kachel, LOOP für Beds, AUTO-CUE für saubere Cue-Starts. Optional an easy EDITOR zum Trimmen schicken.

03

Mode wählen

MULTI-Mode für Stacking, SINGLE-Mode für Cart-Machine-Logik. FADE auf SHORT / MEDIUM / LONG für Cross-Fades zwischen Cues. ESC stoppt alles, Fade-All zieht alle laufenden Pads sauber raus.

04

Show speichern

SAVE schreibt eine .satkip-Datei mit Manifest und allen Audios als 24-Bit-WAV. Per AirDrop oder Files aufs nächste iPad, dort doppelklicken, Show steht.

Technische Details

Built for Live

Native iOS-App auf JUCE-Audio. Background-Audio aktiviert, damit Cues bei gesperrtem Display weiterlaufen.

Pad-Engine

  • Slots 64 (4 Banks x 16)
  • Voices 64 (1 pro Slot)
  • Per-Pad Name · Farbe · Vol
  • LOOP Wraparound zum Cue-Punkt
  • AUTO-CUE Stille-Skip am Anfang
  • Wellenform Mini-Preview mit Cue-Marker

Modes & Steuerung

  • Mode MULTI · SINGLE
  • FADE OFF · 0,5 · 1,5 · 4 s
  • Tastatur 1234 · QWER · ASDF · ZXCV
  • Banks F5 · F6 · F7 · F8
  • Stop All ESC
  • Master-Vol iPad (iPhone via HW-Tasten)

Plattform & I/O

  • iPhone Hoch + Quer
  • iPad alle 4 Orientierungen
  • Input WAV · AIFF · MP3 · M4A · FLAC · OGG
  • Show .satkip (ZIP mit 24-Bit-WAVs)
  • Background Audio-Mode aktiv
  • URL-Scheme instantplayer://
Was es besonders macht

Eine Show.
Eine Datei.

Der Unterschied zu generischen Soundboards ist das .satkip-Bundle: Manifest plus alle 24-Bit-WAVs in einer ZIP. Ein Theater-Abend, eine Podcast-Folge, ein Live-Set, komplett portabel. Vergiss den USB-Stick, vergiss "welche Audios gehören zu welcher Show", AirDrop einfach das Bundle und das Setup ist da, wo es sein muss.
