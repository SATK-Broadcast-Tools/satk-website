In evidenza

File dentro, file fuori.

loudness CORRECT su iPad è la variante mobile dello strumento desktop: stesso motore, stessi preset, stessi layout surround. Con layout orizzontale per un controllo preciso al campione.

16 Presets

Da R128 a YouTube

EBU R128, R128 S1, ATSC A/85, ARIB TR-B32, AGCOM, FreeTV OP-59, DPP, Portaria 354, Netflix, Apple Podcasts, Spotify, Amazon Music, YouTube, Leq(m)-85, Leq(a)-85 e Custom: tutti i target in un'unica lista.

Two-Pass

Verify-and-Refine

Il primo passaggio misura, il secondo scrive con il gain di correzione. Se il risultato si discosta dal target di più di 0,1 LU, parte automaticamente un ulteriore passaggio di affinamento. Niente "più o meno".

True Peak

Limiter polifase 4x

Protezione dai picchi inter-sample con 5 ms di lookahead e 50 ms di release esponenziale. Inviluppo a doppia costante di tempo, nessun artefatto di pompaggio, nessuna distorsione sui transienti.

Surround

Da mono a 9.1.6

Fino a 16 canali: mono, stereo, 5.1, 6.1, 7.1, 7.1.2, 7.1.4, 9.1.4, 9.1.6. Quattro layout di routing (Auto/ITU, Film L-C-R, DTS, Raw/Stems). LFE conforme a BS.1770 con peso 0, surround con 1,41, esattamente secondo specifica.

LRA

Reshape a 3 bande

Attivabile se la LRA è troppo alta. Linkwitz-Riley del 4° ordine con incroci a <= 150 Hz e >= 3 kHz. Compressione soft-knee per banda con costanti di tempo specifiche, ricostruzione perfetta.

Come funziona

In 4 passi a un file che supera il collaudo

Scegli il file, imposta layout e preset, ANALYZE CORRECT, fatto. Verify-and-Refine lavora in background.

01

Scegli il file

WAV, AIFF, FLAC, MP3 dall'app File, iCloud Drive o via AirDrop. Fino a 9.1.6 (16 canali).

02

Layout & preset

Auto/ITU per il multicanale standard, Film/DTS/Raw per i casi speciali. Preset tra 16 target oppure Custom.

03

ANALYZE CORRECT

Il primo passaggio misura LUFS Integrated e TP massimo. Il secondo scrive con gain di correzione e limiter TP. Passaggio di affinamento se lo scostamento supera 0,1 LU.

04

Output in File

Il file corretto finisce nei documenti dell'app. Subito condivisibile dall'app File, via AirDrop, Mail, chiavetta USB-C.

Dettagli tecnici

Built for Broadcast

Lo stesso motore DSP della versione desktop. Riproducibile con precisione al campione, tutti i valori ricontrollati rispetto alla specifica alla fine del secondo passaggio.

Standard & DSP

  • Loudness ITU-R BS.1770-4
  • K-Weight Pre + RLB
  • Gating 400 ms · 75 % Overlap
  • LRA EBU Tech 3342
  • TP-Limiter 4x polyphase FIR
  • Lookahead 5 ms · Release 50 ms

Canali & routing

  • Channels Mono bis 9.1.6 (16)
  • Layouts Auto · Film · DTS · Raw
  • LFE-Gewicht 0 (BS.1770-konform)
  • Surround 1,41 (Power-Domain)
  • LRA-Bands <= 150 / 150-3000 / > 3000 Hz
  • Filter Linkwitz-Riley 4. Ordnung

Piattaforma & I/O

  • OS iPadOS 16+ (iPad-only)
  • Bundle com.satk.loudnesscorrect
  • Orient. Landscape (Left + Right)
  • Input WAV · AIFF · FLAC · MP3
  • Output WAV · AIFF · 16/24/32-Bit
  • UI Dark, Full-Screen, English
Cosa non è

Non è un misuratore in tempo reale.

loudness CORRECT è uno strumento di correzione offline, non un misuratore live. Misura l'intero file, pianifica la correzione, riscrive, verifica. Chi ha bisogno della loudness in tempo reale sceglie pegelWERK loudness METER PRO. Chi vuole portare un mix finito nel corretto corridoio di loudness sceglie questo.
