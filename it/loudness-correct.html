loudness CORRECT è la soluzione mirata, file per file, per una correzione della loudness conforme agli standard. loudness CORRECT condivide il motore DSP con pegelWERK loudness METER PRO: stesso K-weighting, stesso loudness meter, stesso rilevatore True Peak. Ciò che vedi nel meter, qui lo centri.

BS.1770-4

K-weighting + doppio gating

Filtro K ITU-R BS.1770-4 (Pre + RLB), blocchi da 400 ms con sovrapposizione del 75%, gating assoluto a -70 LUFS e relativo a -10 LU. LUFS-I, LUFS-S Max, LUFS-M Max, LRA (EBU Tech 3342): tutti i valori esattamente secondo specifica.

True Peak

Limiter TP polifase 4x

Gli stessi tap polifase del rilevatore TP: ciò che misura, lo limita. 5 ms di lookahead, inviluppo a doppia costante di tempo, 50 ms di release esponenziale. Curve di limitazione pulite e piatte, nessun pompaggio.

LRA

Processore LRA a 3 bande

Linkwitz-Riley del 4° ordine con ricostruzione perfetta. Low <= 150 Hz, Mid 150-3000 Hz, High > 3000 Hz. Compressore soft-knee per banda con inviluppo RMS. Costanti di tempo specifiche per banda: porta qualsiasi LRA nel corridoio di trasmissione.

Verify

Two-pass con Auto-Refine

Il primo passaggio misura, il secondo corregge, il terzo verifica. Se il valore residuo supera 0,1 LU, il passaggio di correzione riparte automaticamente con un guadagno rifinito. Risultato: il tuo target entro +/-0,1 LU.

Come funziona

In 4 passi alla norma

Trascina, clicca, fatto. La pipeline two-pass lavora in background, tu ricevi un file corretto e un report PDF di conferma.

01

Trascina il file

WAV, AIFF, FLAC, MP3. Da mono a 9.1.6, quattro layout di routing (ITU, Film, DTS, Raw). Su macOS tramite selettore di file, su iPad tramite app File / iCloud Drive.

02

Scegli il preset

Uno dei 13 target di consegna oppure Custom con valori LUFS/TP/LRA personalizzati. Correzione LRA e limiter TP attivabili singolarmente.

03

ANALYZE + CORRECT

Il primo passaggio misura LUFS-I/S/M, LRA, TP. Il secondo scrive un nuovo file con gain statico, correzione LRA multibanda opzionale e limiter TP.

04

VERIFY + report

L’output viene rimisurato. Con |Residual| > 0,1 LU il secondo passaggio riparte. Report PDF con Source / Target / Result e badge PASS.
