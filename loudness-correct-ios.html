Highlights

Datei rein, Datei raus.

loudness CORRECT auf dem iPad ist die mobile Variante des Desktop-Tools, gleiche Engine, gleiche Presets, gleiche Surround-Layouts. Im Landscape-Layout für sample-genaue Kontrolle.

16 Presets

Von R128 bis YouTube

EBU R128, R128 S1, ATSC A/85, ARIB TR-B32, AGCOM, FreeTV OP-59, DPP, Portaria 354, Netflix, Apple Podcasts, Spotify, Amazon Music, YouTube, Leq(m)-85, Leq(a)-85 und Custom, alle Targets in einer Liste.

Two-Pass

Verify-and-Refine

Pass 1 misst, Pass 2 schreibt mit Korrektur-Gain. Wenn das Ergebnis um mehr als 0,1 LU vom Target abweicht, läuft automatisch ein weiterer Refine-Pass. Kein „ungefähr".

True Peak

4x Polyphase Limiter

Inter-Sample-Peak-Schutz mit 5 ms Lookahead und 50 ms exponentiellem Release. Dual-Time-Constant-Hüllkurve, keine Pump-Artefakte, kein Distortion an Transienten.

Surround

Mono bis 9.1.6

Bis zu 16 Kanäle: Mono, Stereo, 5.1, 6.1, 7.1, 7.1.2, 7.1.4, 9.1.4, 9.1.6. Vier Routing-Layouts (Auto/ITU, Film L-C-R, DTS, Raw/Stems). LFE BS.1770-konform mit Gewicht 0, Surrounds mit 1,41, exakt nach Spec.

LRA

3-Band Reshape

Optional aktivierbar bei zu hoher LRA. Linkwitz-Riley 4. Ordnung splittet bei <= 150 Hz und >= 3 kHz. Per-Band Soft-Knee-Kompression mit bandspezifischen Zeitkonstanten, perfekte Rekonstruktion.

Files

Files-App Workflow

Input über die Dateien-App, iCloud Drive oder per AirDrop. Output landet in den App-Documents, sofort über die Files-App teilbar oder per AirDrop weiter. Naming: <input>_<preset>.wav.

Funktionsweise

In 4 Schritten zur abnahmesicheren Datei

Datei wählen, Layout und Preset setzen, ANALYZE CORRECT, fertig. Verify-and-Refine läuft im Hintergrund.

01

Datei wählen

WAV, AIFF, FLAC, MP3 aus der Dateien-App, iCloud Drive oder per AirDrop. Bis 9.1.6 (16 Kanäle).

02

Layout & Preset

Auto/ITU für Standard-Multichannel, Film/DTS/Raw bei Spezialfällen. Preset aus 16 Targets oder Custom.

03

ANALYZE CORRECT

Pass 1 misst Integrated LUFS und Max TP. Pass 2 schreibt mit Korrektur-Gain und TP-Limiter. Refine-Pass falls Abweichung > 0,1 LU.

04

Output in Files

Korrigierte Datei landet in den App-Documents. Über die Files-App sofort teilbar, AirDrop, Mail, USB-C-Stick.

Technische Details

Built for Broadcast

Identische DSP-Engine wie die Desktop-Version. Sample-akkurat reproduzierbar, alle Werte am Pass-2-Ende erneut gegen Spec geprüft.

Standards & DSP

  • Loudness ITU-R BS.1770-4
  • K-Weight Pre + RLB
  • Gating 400 ms · 75 % Overlap
  • LRA EBU Tech 3342
  • TP-Limiter 4x polyphase FIR
  • Lookahead 5 ms · Release 50 ms

Channels & Routing

  • Channels Mono bis 9.1.6 (16)
  • Layouts Auto · Film · DTS · Raw
  • LFE-Gewicht 0 (BS.1770-konform)
  • Surround 1,41 (Power-Domain)
  • LRA-Bands <= 150 / 150-3000 / > 3000 Hz
  • Filter Linkwitz-Riley 4. Ordnung

Was es nicht ist

Kein Echtzeit-Meter.

loudness CORRECT ist ein Offline-Korrektur-Tool, kein Live-Meter. Es misst die ganze Datei, plant die Korrektur, schreibt neu, verifiziert. Wer Echtzeit-Loudness braucht, nimmt pegelWERK loudness METER PRO. Wer eine fertige Mischung auf den korrekten Lautheits-Korridor bringen will, nimmt das hier.
